## MODIFIED Requirements

### Requirement: Portfolio image gallery
The system SHALL display Portfolio-membered images on `/portfolio` as a browseable gallery with an uneven / asymmetric visual rhythm (mixed scales), consistent with the public atelier craft system, and without watermarks.

#### Scenario: Visitor browses portfolio
- **WHEN** a visitor opens `/portfolio`
- **THEN** they see Portfolio images only (not storage-only Library images) in an uneven gallery rhythm

#### Scenario: Immersive open from portfolio
- **WHEN** a visitor activates a Portfolio image
- **THEN** they can view it in an immersive larger view and dismiss it
