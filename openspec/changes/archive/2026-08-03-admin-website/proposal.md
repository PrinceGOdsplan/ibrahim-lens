## Why

Site copy, forms, and marketing content need one Website hub; Contact editor owns contact and booking questions together; services use a capped custom package builder.

## What Changes

- Website tabs for Home, About, Services, Testimonials, FAQ, SEO, Globals
- Home featured from Portfolio only; Book CTA scrolls to booking form (public-site)
- Services: custom package builder with **max entries** (default 12)
- Contact editor: contact fields + booking questions (**max 8**)
- Testimonials manual + promote-from-feedback after edit
- No email provider in this change

## Capabilities

### New Capabilities
- `website-content`: CMS including capped services packages and Portfolio-sourced featured picks
- `website-forms`: Contact + booking questions (max 8) in one editor
- `website-seo`: SEO metadata for key public pages

### Modified Capabilities
- (none)

## Impact

- Public pages consume content/forms
- Non-goals: Library uploads, delivery tokens, Resend
