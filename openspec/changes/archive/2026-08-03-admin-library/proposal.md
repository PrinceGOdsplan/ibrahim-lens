## Why

The photographer needs one Library hub as the source of truth for finished images, then opt-in to Portfolio, albums, Work, or Deliveries — without separate upload worlds.

## What Changes

- Library media pool with max upload size; originals + thumbnails; storage-only allowed
- No watermarks in v1
- Portfolio membership; Home featured from Portfolio only
- Albums; Work (private by default; Show on website opt-in)
- Portfolio tags managed under Settings (simple tag list)
- Brand assets (logo)

## Capabilities

### New Capabilities
- `library-media`: Upload/store finished images with size limits; originals + thumbnails; no watermarks
- `library-portfolio`: Flag/curate Library images for public Portfolio
- `library-albums`: Group Library images into albums
- `library-work`: Work projects from Library images; website visibility opt-in
- `library-categories`: Portfolio tags (settings-managed) and assignment
- `library-brand-assets`: Logo and brand media

### Modified Capabilities
- (none)

## Impact

- Feeds public Portfolio/Work and Clients Deliveries
- Non-goals: delivery UX, CMS copy, email, watermarking
