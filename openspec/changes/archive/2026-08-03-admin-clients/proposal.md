## Why

The photographer needs Studio tools to deliver images privately, collect feedback, manage booking requests, and see one Inbox.

## What Changes

- Clients hub: Deliveries, Feedback, Bookings, Inbox
- Deliveries from images / album(s) / Work; **client name required**
- Expiry: **7 days after creation only** (countdown for clients)
- View, download originals, feedback; promote feedback to testimonials after edit
- Bookings confirm/contact; one Inbox
- No share passwords; no email in v1

## Capabilities

### New Capabilities
- `client-deliveries`: Create/manage delivery links with client name and 7-day expiry
- `client-gallery`: Token gallery with downloads and countdown
- `client-feedback`: Feedback; promote to testimonials after edit
- `client-bookings`: Manage booking requests
- `client-inbox`: Unified inbox

### Modified Capabilities
- (none)

## Impact

- Depends on Library + Website forms
- Non-goals: post-download expiry, passwords, Resend, availability calendars
