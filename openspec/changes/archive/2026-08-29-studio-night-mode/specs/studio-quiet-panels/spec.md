## MODIFIED Requirements

### Requirement: Quieter Studio inputs
Studio form controls on Website and Library SHALL use the active Studio appearance palette (light or Soft-night–related night) with thinner borders and less boxed chrome than heavy outline card buttons, without adopting public Soft night visitor form styling or Syne/Sora.

#### Scenario: Edit a text field on light
- **WHEN** the photographer focuses an input in a quiet section on the light desk
- **THEN** the control remains Studio-light with restrained border treatment

#### Scenario: Edit a text field on night
- **WHEN** the photographer focuses an input in a quiet section while night mode is active
- **THEN** the control uses night Studio tokens with restrained border treatment rather than public Soft night form chrome
